# Ficha Studio — implementação M1

Next.js serve editor com imagem original e campos fixos; React Query consulta Fastify. DTO Zod único em packages/shared. Adapter backend Anthropic recebe imagem por clique explícito, valida saída e mantém credencial no servidor. Sem chave, extração indisponível e preenchimento manual funciona.

FichaRecord inclui imagem original, campos, avisos e marcação de exemplo. IndexedDB armazena biblioteca local; backup JSON validado permite transporte entre navegadores. Impressão A4 usa documento dedicado com imagem de 110mm e grupos textuais livres para continuar em páginas seguintes.

Skill global orquestrar-build atualizada para Codex, validada e revisada. Desenvolvimento pelos agentes nativos em territórios disjuntos. Evidências em specs/RECONCILE-REPORT.md. M1 aguardando HTC, sem GitHub remoto e VPS por enquanto.
