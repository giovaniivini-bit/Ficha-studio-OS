# M1 — Jornada

Enviar JPEG/PNG/WebP → visualizar original → extrair quando IA configurada → revisar campos fixos e avisos → salvar no navegador → reabrir → imprimir ou salvar PDF.

Upload rejeita formato inválido ou imagem acima de 10 MB com mensagem. Extração apresenta loading, falha acionável e não substitui edições sem confirmação. Campos têm rótulos e são agrupados. Ficha vazia funciona para preenchimento manual. Exemplos vêm preenchidos por transcrição de referência, claramente identificados; não simulam chamada de IA. Troca de imagem/documento avisa sobre edições não salvas. Biblioteca permite reabrir e excluir com confirmação. Falha de armazenamento local é visível. Importação/exportação JSON permite backup local.

Fora do M1: integração automática Drive, acesso multiusuário, autenticação, custos, consumo e cálculo de medidas não presentes. Dados do Drive foram usados somente na descoberta.
