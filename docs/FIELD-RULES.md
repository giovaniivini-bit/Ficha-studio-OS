# Campos — regras acordadas com o usuário

1. MODELAGEM: código literal do rodapé. Top MC D.200 significa top manga curta, modelagem Disney 200. Não substituir por nome genérico e não inventar um código a partir do desenho.
2. Estação / ano: conservar estação e ano, sem sigla entre parênteses. ETIQUETA recebe essa sigla (CFC, CVA, CYC etc.) separadamente. Isso se refere ao cabeçalho, não a todo conteúdo entre parênteses da peça.
3. Linha removido da ficha atual. Versão anterior permanece preservada no legado para evitar perda de histórico.
4. Uma entrada para cada COR: número, COR/nome, PANTONE e CÓDIGO. Exemplo Cor02: 2026 Flint Stone | 19-3916 | MC7062615. Não interpretar2026 como ano quando faz parte do nome da cor, nem alterar zeros/códigos.
5. Quatro campos fixos Aviamento1..4, um item por campo. TAG BCI e selo de detalhe interativo são aviamentos. Não confundir esses itens com ETIQUETA/sigla do cabeçalho. Excedentes em observações com aviso, sem descartar.
6. Estampa e Bordado separados; Aplique também tem campo próprio para não misturar operações. Registrar código/fornecedor e medida quando legíveis.

Fichas antigas são convertidas conservadoramente e precisam de conferência. Novas extrações seguem o schema atual. Modelo Python e dataset devem acompanhar o novo contrato; não retomar treinamento nesta etapa.
